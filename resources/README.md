# Resources

This directory contains detailed guidance on essential readings organised by theme. Each resource document provides:

- Annotated recommendations for texts and materials
- Specific chapters and sections to prioritise
- Implementation notes and practical guidance
- Integration with the overall curriculum progression

## Resource Documents

- `mathematical-foundations.md` - Core mathematical prerequisites and advanced topics
- `econometric-methods.md` - Time series analysis, causal inference, and statistical learning
- `market-microstructure.md` - Microstructure theory, empirical analysis, and algorithmic trading
- `programming-practices.md` - Python implementation, software engineering, and reproducibility
- `advanced-topics.md` - Machine learning in finance, factor models, and research frontiers

Each document emphasises rigorous, validated approaches over trendy but untested methods.
