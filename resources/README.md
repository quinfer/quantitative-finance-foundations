# Reading guides

Choose the guide that helps with the question you are working on. Each guide suggests what to read, what to calculate and how to check the result. The curriculum sets out the order in which these questions arise. [Curriculum](../CURRICULUM.md)

- [Mathematical foundations](mathematical-foundations.md) connects probability and linear algebra to simulation and portfolio risk.
- [Programming practices](programming-practices.md) shows how to turn a calculation into an analysis that someone else can run and inspect.
- [Econometric methods](econometric-methods.md) covers forecasting, inference and the conditions needed for a causal comparison.
- [Market microstructure](market-microstructure.md) explains how orders become trades and how to measure the cost of execution.
- [Advanced topics](advanced-topics.md) brings those methods together in factor investing, machine learning and research with alternative data.

To follow a textbook method into a published application, choose a paper from the [annotated reading list](../papers/essential-readings.md).
