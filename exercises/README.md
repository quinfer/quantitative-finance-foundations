# Exercises

This directory contains implementation tasks building practical capabilities. Each exercise includes:

- Clear specification of the task and learning objectives
- Suggested data sources and preprocessing steps
- Expected outputs and validation criteria
- Extension opportunities for deeper exploration

## Exercise Structure

Exercises are organised by curriculum phase, matching the progression in `CURRICULUM.md`:

### Phase 1: Foundations (Months 1-3)

- `task-01-portfolio-returns/` - Download data, compute portfolio returns, calculate performance metrics
- `task-02-mean-variance/` - Implement Markowitz optimisation with constraints
- `task-03-garch-estimation/` - Estimate volatility models using maximum likelihood

### Phase 2: Econometric Methods (Months 4-6)

- `task-04-volatility-models/` - Compare GARCH variants and evaluate forecasts
- `task-05-cointegration-pairs/` - Test cointegration and implement pairs trading
- `task-06-regularisation/` - Apply Ridge, Lasso, and Elastic Net to return prediction

### Phase 3: Market Microstructure (Months 7-9)

- `task-07-tick-data-analysis/` - Measure spreads and liquidity using high-frequency data
- `task-08-optimal-execution/` - Implement Almgren-Chriss framework
- `task-09-order-book-simulation/` - Build limit order book simulator and test strategies

### Phase 4: Advanced Applications (Months 10-12)

- `project-01-systematic-strategy/` - Develop and backtest factor-based strategy
- `project-02-microstructure-research/` - Complete empirical research project
- `project-03-research-pipeline/` - Build production-quality analysis pipeline

## Completion Criteria

Exercises are considered complete when:

1. Implementation produces correct results matching specifications
2. Code follows best practices (documented, tested, reproducible)
3. Analysis includes proper interpretation and limitation discussion
4. Results are presented clearly with appropriate visualisations

Quality matters more than speed. Take time to understand methods deeply and implement them correctly.

## Getting Help

If stuck on an exercise:

1. Review relevant sections in recommended texts
2. Examine similar implementations in `implementations/` directory
3. Search for methodological details in `papers/` collection
4. Consult `resources/` documents for additional guidance

Document what you tried and what didn't work. This record proves invaluable for learning and future reference.
