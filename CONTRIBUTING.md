# Contributing

A contribution should help a student answer a financial question or check a result. State where it fits in the curriculum, what the student needs to know and what they should be able to explain or reproduce afterwards. The README describes the two entry routes for finance and computer science students. [Where to start](README.md#where-to-start)

## Suggest a reading

Open an issue with the full citation, the chapters or sections to read and the task the reading supports. Explain what it adds to the existing material and identify the evidence or argument a student should examine. For papers, link to a version that readers can access. Include PDFs only when you have permission to redistribute them. [Annotated reading list](papers/essential-readings.md)

## Contribute an exercise or example

State the task, describe the inputs and name an output the student can check. Give the commands and dependency versions needed to reproduce it. For empirical examples, record the source, sample, preprocessing and assumptions. Include a test or a worked calculation with a known result. Put optional extensions after the core task. [Programming practices](resources/programming-practices.md)

## Submit a pull request

Work on a branch in your fork and submit a pull request that explains what changed and how you checked it. Review will focus on the value of the change to the student, the evidence behind it, and whether someone else can reproduce and maintain it. Keep discussion focused on the work and treat other contributors with respect.

Contributions are credited in the repository history and use the repository's Creative Commons Attribution 4.0 International licence. [Licence](LICENSE)
